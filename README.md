# System Cursor

A Minecraft 1.12.2 Cleanroom mod that brings modern mouse cursor behavior to older Minecraft versions.

## 📖 About

**System Cursor** is a lightweight Minecraft 1.12.2 mod designed to bring modern mouse cursor behavior to older versions of Minecraft.

The mod allows Minecraft to dynamically change the mouse cursor depending on the current interaction or UI element, providing a more modern desktop-style experience.

## ✨ Features

- Modern mouse cursor behavior for Minecraft 1.12.2
- Dynamic cursor changes based on the current interaction
- Support for multiple system cursor types
- Lightweight and focused on cursor behavior
- Designed specifically for Cleanroom
- No unnecessary gameplay changes

### Supported Cursor Types

The project is designed to support system cursor types such as:

| Cursor | Description |
|---|---|
| Arrow | Default cursor |
| Hand | Used for clickable elements |
| Text / I-Beam | Used for text input or text selection |
| Crosshair | Precision selection |
| Wait | Indicates that the application is busy |
| App Starting | Indicates that an application is starting |
| Size NS | Vertical resizing |
| Size WE | Horizontal resizing |
| Size NWSE | Diagonal resizing |
| Size NESW | Diagonal resizing |
| Size All | Moving or dragging |
| No | Indicates that an action is unavailable |
| Help | Help cursor |

> Support for individual cursor types may change during development.
